This is an entry for the make.fun bounty
[One-Line Roast: The Gadget You Use Every Day](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).
When run, `main.py` (Python standard library only) writes exactly one line
to `/output/entry.txt`: a roast of the robot vacuum that has mapped the
whole house in perfect detail and still eats the same charging cable every
single morning. A smart machine, outsmarted daily by a cable it already
knows is there. The program is deterministic and writes the same line on
every run.
